# NewsFlow

NewsFlow is a backend-first news publishing platform built with Java 21 and Spring Boot.

The project is being developed as a learning and portfolio project, with a focus on clean code, REST API design, automated testing, and maintainable backend architecture.

## Planned Features

- Article creation, editing, and retrieval
- Article categories and publication workflows
- Pagination and search
- Video upload and media metadata management
- PostgreSQL persistence
- Input validation and centralized error handling
- Automated tests
- OpenAPI documentation

## Technology Stack

- Java 21
- Spring Boot 3.x
- Maven
- Spring Data JPA
- PostgreSQL
- JUnit 5 and Mockito
- OpenAPI / Swagger

## Architecture

NewsFlow is planned as a modular monolith with clearly separated responsibilities for API handling, application logic, domain rules, and infrastructure.

## Project Status

**In development.** Features will be implemented incrementally, with tests and documentation added as the project evolves.

## Running Locally

Setup instructions will be added after the initial application and database configuration have been verified.

## Learning Goals

- Build maintainable Spring Boot REST APIs
- Apply object-oriented design and separation of concerns
- Implement secure file-upload workflows
- Test business rules and persistence
- Practice Git-based development and documentation
